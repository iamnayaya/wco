| Data-residency compliance | Per region | Local storage/law requirements |

## Roles in the data ecosystem

- **WCO (us)** = **processor** for merchant data; **controller** for our own (e.g., account) data.
- **Merchant (you)** = **controller** for your customers' data — you decide how it's used and must honor customer rights.
- **Customers / end users** = **data subjects** with rights over their personal data.

## Core commitments
1. **Privacy by design & default** — minimization, transparency, security built-in.
2. **Lawful processing** — clear legal bases for each processing activity.
3. **Data subject rights** — access, correction, deletion, portability, objection (see each regional doc).
4. **Security** — technical/organizational controls (see [Security documentation](../security/README.md)).
5. **Accountability** — audit trail, DPAs, evidence, breach notification.
6. **Transparency** — published Privacy Policy, Terms, and these docs.
