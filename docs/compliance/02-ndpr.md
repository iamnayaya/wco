# NDPR Compliance

How WCO meets the **Nigeria Data Protection Regulation (NDPR 2019)** and aligns with the newer **Nigeria Data Protection Act (NDPA 2023)** framework, which applies to processing personal data of data subjects in Nigeria.

## 1. Scope
- NDPR/NDPA applies to all personal data of data subjects in Nigeria, processed by residents or non-residents that process such data.
- WCO operated in Nigeria (markets: NGN merchants) is in scope.

## 2. Core obligations

| Obligation | WCO approach |
|---|---|
| **Lawfulness / consent (or other valid basis)** | Legitimate processing bases; consent for marketing |
| **Data subject rights** | Access, correction, deletion, portability, objection |
| **Data minimization** | Collect only what's needed |
| **Security of processing** | Technical/organizational controls (encryption, RBAC, audit) |
| **Data breach notification** | Notify the Nigeria Data Protection Commission (NDPC) and affected subjects within prescribed timelines when required |
| **Registration / certification (as applicable)** | Align with NDPC registration/certification requirements |
| **Local representative** | Appoint/liaise where required for foreign controllers/processors |

## 3. Data subject rights (mirrors GDPR-style rights)
Same rights as GDPR: access, rectification, erasure, restriction, portability, objection, and withdrawal of consent. Fulfilled via dashboard features (profiles, export, delete) and the DSR process in the [Compliance playbook](../playbooks/07-compliance-playbook.md#4-handling-data-subject-requests-dsrs).

## 4. Privacy policy & transparency
- A clear Privacy Policy is published (wco.com/privacy) covering collection, use, disclosure, and retention.
- Consent records are maintained for marketing.

## 5. Breach notification (NDPA/NDPR)
- On a personal-data breach, NDPC notification is required within the mandated window.
- Governed by [Compliance playbook](../playbooks/07-compliance-playbook.md#5-breach-notification) + [Security incident playbook](../playbooks/06-security-incident-playbook.md).

## 6. Data protection officer / contact
- If required (based on processing scale), a DPO is designated.
- Contact: support@wco.com / privacy@wco.com.

## 7. Audit & evidence
- Control evidence (audit logs, Security Hub) supports NDPC audits per [Compliance runbook](../runbooks/compliance.md).
- Data classification and retention per [Data retention](./05-data-retention.md).
