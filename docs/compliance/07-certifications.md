# Compliance Certifications

WCO's certifications, standards alignment, assessments, and public attestation posture.

## 1. Standards alignment

| Standard/Regulation | Status | Notes |
|---|---|---|
| **ISO/IEC 27001:2022** | Aligned (control baseline) | We map to ISO 27001 controls; pursuing/embedded as part of the operating program |
| **NIST 800-53** | Aligned (security controls) | Control catalogue referenced for evidence |
| **GDPR** | In compliance program | [GDPR](./01-gdpr.md) |
| **NDPR / NDPA (Nigeria)** | In compliance program | [NDPR](./02-ndpr.md) |
| **POPIA (South Africa)** | In compliance program | Data-protection for SA subjects |
| **PCI DSS** | Minimal-scope (SAQ-A-type model) | [PCI DSS](./03-pci-dss.md) |
| **SOC 2** | Program in progress | Optional trust reporting (roadmap) |

> This page represents current posture as of the version date. Certification status is updated as assessments are completed. For the latest attestation documents (reports, certificates, DPA templates), contact **privacy@wco.com** or **security@wco.com** under NDA where required.

## 2. What we attest to

- **Security controls** per ISO 27001 / NIST 800-53 (access control, encryption, monitoring, incident response, business continuity).
- **Data protection** per GDPR/NDPR/POPIA (rights, minimization, retention, breach notification).
- **Payment scope** per PCI DSS (minimal scope; no PAN storage).

## 3. Completing a customer / partner security review

To support customer/partner **security questionnaires and vendor reviews**:

1. Download our **security & compliance overview** (contact security@wco.com).
2. **NDA** applies for detailed/attestation documents.
3. Provide configuration/architecture info as needed per [Security documentation](../security/README.md).

## 4. Reporting a concern or requesting a report

- **security@wco.com** — security questionnaires, reports, DPAs.
- **privacy@wco.com** — data protection, DSRs.
- Coordinated disclosure: [`SECURITY.md`](../../SECURITY.md).

## 5. How certifications are maintained
Certifications are an ongoing program, not a one-time event:

- Continuous evidence collection ([Compliance runbook](../runbooks/compliance.md)).
- Annual readiness/review internally, external audit when a certification is held.
- Quarterly access review + posture review ([Compliance playbook](../playbooks/07-compliance-playbook.md)).
- 3rd-party assessments schedule iterated by the compliance program owner.
