# User Troubleshooting

Common problems merchants run into and how to fix them. For the full support-team guide (with diagnosis and escalation), see the [Troubleshooting guides](../troubleshooting/README.md).

## Login issues

| Problem | Fix |
|---|---|
| Wrong password | Use **Forgot password** on the login screen → reset via email/SMS |
| Not receiving reset email | Check spam; confirm the right email; wait a couple of minutes and retry |
| Account locked | Too many failed attempts — wait and retry, or use **Forgot password** |
| 2FA not working | Ensure correct code/time; use recovery codes you saved; contact support |

## WhatsApp issues

| Problem | Fix |
|---|---|
| AI not replying | Check WhatsApp connected (Settings → WhatsApp) + AI enabled (Settings → AI) |
| Number not connecting | Re-scan the QR; ensure the account is valid and not banned by Meta |
| No messages showing | Confirm the WhatsApp number is set as your business number in WCO |

## Payment issues

| Problem | Fix |
|---|---|
| Customer's payment not reflecting | Check order status; confirm provider connected; ask customer to confirm payment |
| Payment link not working | Generate a new link; check provider status in Settings → Payments |
| Can't add payout account | Verify bank details at your provider |

## Delivery issues

| Problem | Fix |
|---|---|
| No delivery provider | Connect one in Settings → Delivery |
| Quote taking long | Try another provider or contact provider support |
| Delayed delivery | Check tracking; contact provider |

## Product / order issues

| Problem | Fix |
|---|---|
| Product not showing to customers | Ensure it's **active** and has stock |
| Wrong price shown | Update the product in Products |
| Order stuck in Draft | Confirm it |

## App issues

| Problem | Fix |
|---|---|
| App won't load | Check connectivity; update the app; restart |
| Not getting notifications | Enable notifications in device + app settings |
