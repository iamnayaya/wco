# Mobile App Guide

Run your store from anywhere with the WCO mobile app (iOS & Android). It's built with the same features as the web dashboard, optimized for on-the-go.

## Getting the app

- **iOS:** App Store → search "WhatsApp Commerce OS" or "WCO".
- **Android:** Google Play → search "WCO" / "WhatsApp Commerce OS".

> The app requires a stable internet connection (works on mobile data or Wi-Fi).

## Signing in

- Log in with the same account you use on the web dashboard.
- Support for **2FA** just like the web.
- Stay signed in with **biometric** login (FaceID / fingerprint) if enabled — see Settings → Account.

## What you can do in the app

| Feature | Description |
|---|---|
| **Dashboard** | Revenue, orders, customers, unanswered messages at a glance |
| **Orders** | View, confirm, process, arrange delivery |
| **Products** | Add/edit products, adjust stock |
| **Customers** | View profiles, tags, history |
| **Messages** | Answer conversations, review AI replies |
| **Analytics** | Quick sales & performance reports |
| **Settings** | Account, store, WhatsApp, payments (view), AI, notifications |

## On-the-go workflows

### Confirm an order fast
New order notification → open app → **Orders** → **Confirm** → done.

### Answer an unanswered customer
**Messages → Unanswered** → tap the thread → reply. (Unanswered = potential sales!)

### Restock from anywhere
**Products → tap product → stock +** → save.

### Check your money
**Analytics / Payments** → see today's revenue and payout status.

## Notifications

The app sends push notifications for what you enable in **Settings → Notifications**:
- New order
- Payment received
- Unanswered message
- Low stock
- Delivery updates

Keep notifications on so you never miss a sale.

## Offline handling

- The app caches recent data for quick viewing.
- Actions (e.g., confirming an order) are queued and sync when you're back online.
- Payment links and messages need connectivity.

## Troubleshooting

| Issue | Fix |
|---|---|
| App won't log in | Check connectivity; update app; reset password |
| Not getting notifications | Enable notifications in device Settings + app Settings |
| Changes not syncing | Refresh; re-open app; check internet |
| App is outdated | Update from the App Store / Play Store |
| Missing feature | Confirm your plan tier; some features are web-only |
