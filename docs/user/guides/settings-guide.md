# Settings Guide

Configure every part of your WCO account and store. Settings is organized into clear sections.

## Sections overview

| Section | What you configure |
|---|---|
| **Account** | Your profile, password, security |
| **Store** | Store name, category, currency, location |
| **WhatsApp** | Connect/manage your WhatsApp number |
| **Payments** | Payment providers + payout account |
| **Delivery** | Logistics providers + rates |
| **AI** | Auto-responder, templates, handoff |
| **Notifications** | Alerts (orders, low stock, messages) |
| **Team / Members** (if on a team plan) | Invite staff, set roles |
| **Privacy** | Data controls (export, consent) |

## Account settings

- **Profile** — name, email, phone, photo.
- **Password** — change your password (use a strong, unique one).
- **Two-factor authentication (2FA)** — highly recommended; adds an extra login step.
- **Sessions** — see and log out other devices.

## Store settings

- **Store name & category** — shown to customers.
- **Currency** — e.g., NGN, GHS, KES (set carefully; affects pricing).
- **Location & timezone** — used for delivery areas and reporting.
- **Operating hours** — when you're "open" (AI can note this).

## WhatsApp settings

- **Connect number** — link your business WhatsApp number.
- **Status** — connected/disconnected.
- **Disconnect** — unlink the number (customers can no longer message via WCO).
- Manage the number used for message broadcasts.

## Payments settings

- Connect **Paystack / Flutterwave / OPay**.
- Add a **payout account** (bank).
- View **payout** balance & history.
- See payment **status** (active/failed).

## Delivery settings

- Connect **GIG / Kwik / Sendy**.
- Set **delivery rates** and **areas**.
- Default provider per region, if supported.

## AI settings

- **Enable/disable** the auto-responder.
- **Response templates** — default + custom FAQs.
- **Handoff** — when to route to you (buying intent, unresolved).
- **Language/voice** — set tone and language (e.g., English + local languages).

## Notifications

Choose what alerts you get and how (in-app / push / email / SMS):

- New order
- Payment received
- Low stock
- Unanswered message
- Delivery status change

## Team / members

If your plan supports a team:

- Invite staff via email/phone.
- Assign **roles**: Owner, Admin, Agent, Viewer.
- Roles control access — see [Security](../security/README.md) for the role matrix.

> Tip: never share your account password; use team members with their own logins instead (more secure + auditable).

## Privacy settings

- **Data export** — download a copy of your store data.
- **Consent** — manage customer data settings (subject to GDPR/NDPR).
- Customer data rights — see [Compliance](../compliance/README.md).

## FAQ

| Question | Answer |
|---|---|
| I changed my currency — will prices update? | Yes, but review products after. |
| Can I use multiple payment providers? | Yes — offer several. |
| How do I add a store manager? | Settings → Team → Invite with the Admin role. |
| Is 2FA available? | Yes — turn it on in Account. |
