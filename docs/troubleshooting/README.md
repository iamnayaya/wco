## Support channels
- **In-product help** → surfaces these guides contextually.
- **Email:** support@wco.com
- **Community / help center** (platform)
- **Status page:** https://status.wco.com (for outages — check first if many users report the same issue)

## Golden rules for support
1. **Check the status page** first — if there's known outage, tell the user it's being worked on.
2. **Get the essential facts**: account/store, what they did, what they expected, what happened, error message/`requestId`.
3. **One issue per ticket** — keep it resolvable.
4. **Resolve fast, document always** — every fix that recurs becomes a new troubleshooting section.
5. **Escalate promptly**: don't guess on payment/data/security matters.
